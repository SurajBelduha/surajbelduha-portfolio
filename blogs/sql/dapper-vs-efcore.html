Why We Chose Dapper Over Entity Framework Core for FinTech Transaction Processing

Suraj Prajapati Senior .NET Backend Developer • FinTech Specialist

In payment engines handling 10,000+ concurrent transactions per second, every millisecond and byte of garbage collection matters. While Entity Framework Core offers great developer velocity, Dapper micro-ORM provides raw SQL performance and zero change-tracking overhead.

High-Throughput Dapper Query Example

public async Task<MerchantWalletDto?> GetWalletForUpdateAsync(long merchantId, IDbTransaction transaction)
{
    const string sql = @"
        SELECT MerchantId, Balance, LockedBalance, Currency 
        FROM MerchantWallets WITH (UPDLOCK, HOLDLOCK) 
        WHERE MerchantId = @MerchantId;";

    return await transaction.Connection.QueryFirstOrDefaultAsync<MerchantWalletDto>(
        sql, new { MerchantId = merchantId }, transaction: transaction);
}
