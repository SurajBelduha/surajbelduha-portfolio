Building Bank-Grade Webhook Verification in ASP.NET Core with HMAC-SHA256

Suraj Prajapati Senior .NET Backend Developer • FinTech Specialist

In high-volume payment processing platforms, incoming webhooks deliver status notifications for Pay-in and Payout operations. Securing these callback HTTP endpoints against request spoofing, replay attacks, and payload tampering is paramount.

HMAC-SHA256 Signature Verification Service in C#

public class HmacValidationService
{
    public static bool VerifySignature(string rawBody, string secretKey, string headerSignature)
    {
        using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(secretKey));
        var hashBytes = hmac.ComputeHash(Encoding.UTF8.GetBytes(rawBody));
        var computedSignature = Convert.ToHexString(hashBytes).ToLower();

        return CryptographicOperations.FixedTimeEquals(
            Encoding.UTF8.GetBytes(computedSignature),
            Encoding.UTF8.GetBytes(headerSignature.ToLower())
        );
    }
}
