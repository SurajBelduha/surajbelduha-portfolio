Structuring Enterprise .NET Core Solutions: CQRS & MediatR in Practice

Suraj Prajapati Senior .NET Backend Developer • FinTech Specialist

In enterprise solutions, keeping controllers thin and decoupling business workflows from HTTP infrastructure is key. Combining CQRS (Command Query Responsibility Segregation) with MediatR provides clean separation of concerns.

Command & Handler Pattern in MediatR

public record InitiatePayoutCommand(long MerchantId, decimal Amount, string BankAccount) : IRequest<PayoutResult>;

public class InitiatePayoutHandler : IRequestHandler<InitiatePayoutCommand, PayoutResult>
{
    private readonly IPayoutRepository _repo;
    public InitiatePayoutHandler(IPayoutRepository repo) => _repo = repo;

    public async Task<PayoutResult> Handle(InitiatePayoutCommand cmd, CancellationToken cancellationToken)
    {
        return await _repo.ExecutePayoutAsync(cmd.MerchantId, cmd.Amount, cmd.BankAccount, cancellationToken);
    }
}
