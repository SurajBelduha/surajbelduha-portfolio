📋 Parameter Guide & Dictionary

merchantId

Unique merchant account code mapped to API keys and settlement rules.

amount & currency

Transaction value formatted in decimals along with ISO currency ("INR").

signature (HMAC-SHA256)

Cryptographic signature hash generated from request payload + secret key.

bankReferenceNo (RRN / UTR)

Unique 12-digit bank reference number assigned by gateway for reconciliation.
